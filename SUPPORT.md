# Support

Report reproducible problems in [Issues](https://github.com/yqlay/MCAI/issues).
Include the MCAI file/version, Minecraft and loader versions, game Java version,
Windows version, reproduction steps, expected result and actual result.

For display/input problems, include windowed/fullscreen mode, display scaling,
input method and the relevant key binding. For model problems, include the
protocol, public model identifier and sanitized status/error text.

Never post API keys, bearer tokens, private conversations, connection profiles
or an entire instance directory. Inspect screenshots before attaching them.
Keep the original world and task/job record when reporting a construction issue.
Check whether a request was accepted before resending a world-changing action.

Use a backup and a separate test world for a new game version or mod combination.
Do not delete histories or force-kill unrelated Java processes as a first step.
